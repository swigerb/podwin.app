Privacy policy

Last updated: November 23, 2026

Who publishes PodWin

PodWin is published by MightyB. This policy describes the PodWin desktop app and this website.

What PodWin accesses locally

PodWin reads local runtime versions and session, container, and image metadata. It also reads requested output so it can display it in the app. Names, paths, and output can identify people or contain sensitive information.

PodWin does not include usage analytics, advertising, behavioral tracking, or remote crash reporting.

PodWin keeps local, redacted, size-bounded diagnostics. Diagnostic files contain fixed operation and failure events and numeric HRESULTs. They do not contain credentials, environment values, inspect payloads, command input or output, or container logs. Diagnostic files remain on your device and are never uploaded. You can share them only if you choose to do so.

What PodWin stores and where

PodWin saves settings such as appearance, window position and size, and sandbox preferences. It does not save container output or log snapshots automatically.

The Direct build stores settings at %LOCALAPPDATA%\PodWin.Settings.Direct\settings.json. Its redacted diagnostics are at %LOCALAPPDATA%\PodWin\logs. Direct-owned sessions use %LOCALAPPDATA%\PodWin.Sessions.Direct.

The Store build stores settings in the package LocalFolder and diagnostics in that folder's logs subdirectory. The Store build doesn't create PodWin-owned sessions. Windows may remove package local data when the Store app is reset or uninstalled.

The optional Store Start at sign-in choice is stored by Windows as a startup-task state. PodWin keeps no copy of that choice. The Direct build can add a per-user Windows startup entry only after your explicit confirmation in Settings. PodWin reads its startup state and removes only the Direct entry during uninstall.

Network connections

The Direct build checks for stable releases against GitHub Releases only when you request it. It does not poll in the background or apply updates automatically. A download requires your confirmation, and GitHub can receive request metadata such as your source IP address.

When you consent to an image pull in the Direct build, the registry you choose receives the image request and associated network information, including authentication information if you supply it. GitHub Releases and registries have their own privacy practices. The Store build uses Store-managed updates and excludes the Direct update code and Velopack.

Agent sandboxes (Direct build): creating a sandbox pulls the requested public image from its registry after consent, and sandbox containers run with networking disabled. If you enable MCP for a launch, PodWin listens only on a local named pipe secured to your Windows account, and the separately published sidecar connects to it. Neither opens a network listener.

When you choose to open a published container port, PodWin asks Windows to open the link in your default browser. PodWin does not itself request the link.

WSL and container workloads can make their own network requests. PodWin's local-first design does not control or prevent those requests.

Microsoft's own privacy statement covers WSL, Windows, and the Microsoft Store: Microsoft Privacy Statement.

Your controls

You choose what PodWin displays and what information you copy or share. A log snapshot leaves PodWin only when you choose Copy or Save. Copy puts the snapshot on the Windows clipboard. Save writes it to a file that you choose in the Windows save dialog.

You can change appearance and startup preferences in Settings. You can remove Direct settings and logs manually while PodWin is closed. Store app-data retention across upgrades, reset, and uninstall depends on the installed package and Windows.

If you email support at support@podwin.app, the information you choose to send leaves your device. Registries and container workloads can have their own privacy policies.

Children

PodWin is not directed to children. A parent or guardian who allows a child to use the app should review local container data and anything copied or sent to another service.

Changes to this policy

When PodWin changes how it handles data, MightyB may update this policy. The Last updated date at the top shows the latest revision.

Contact

Questions or privacy requests: support@podwin.app.
